## Раскрывающиеся подсказочки

```
!!! note "Заголовок"
    Текст заметки с обязательным отступом в четыре пробела.

!!! tip "Заголовок"
    Текст подсказки с обязательным отступом в четыре пробела.
```

!!! tip "Фишечка"
Если написать ???+ note, блок будет по умолчанию развернут, но его можно будет свернуть вручную.
