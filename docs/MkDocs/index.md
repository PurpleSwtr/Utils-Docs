## Раскрывающиеся подсказочки

```
!!! note "Заголовок"
    Текст заметки с обязательным отступом в четыре пробела. - открыто

??? tip "Заголовок"
    Текст подсказки с обязательным отступом в четыре пробела. - скрыто
```

!!! tip "Фишечка"
    Если написать ???+ note, блок будет по умолчанию развернут, но его можно будет свернуть вручную.

### Какие бывают 

!!! note


!!! abstract


!!! info


!!! tip


!!! success


!!! question


!!! warning


!!! failure


!!! danger


!!! bug


!!! example


!!! quote
