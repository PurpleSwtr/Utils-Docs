## JSONL

Узнал что сущесвтует такой формат, где содержится такой же JSON, но не ЕДИНЫМ объектом, а каждый объект представлен на своей строчке:

### JSON


```JSON
[
  {"id": 1, "name": "Иван"},
  {"id": 2, "name": "Анна"}
]
```

### JSONL

```JSONL
{"id": 1, "name": "Иван"}
{"id": 2, "name": "Анна"}
```

Это должно быть супер удобно при парсинге большого количества объектов построчно, не требует парсинга всего объекта сразу, и соотвественно экономим память - круто!
