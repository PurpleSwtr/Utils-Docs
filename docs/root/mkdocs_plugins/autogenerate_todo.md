По итогу не очень понравилось как это всё читается и организованно в целом, когда там довольно много записей и пунктов.

Я даже написал скрипт, который через библиотеку преобразует списки в форматированные таблички в таком формате:

```python

from tabulate import tabulate

md_table = tabulate(data, headers=["Текущие задачи", "Выполнено"], tablefmt="github")

```

Более простой вариант списком мне показался более простым и понятным.
Добавил сортировку на выполненные и текущие, чтобы было проще ориентироваться, и не сильно запариваться при форматировании.

??? note "Открыл для себя удобную функцию в itertools"
    
    В процессе поиска более элегантного решения, даже удалось познакомиться с 

    ```python
    for u_task, c_task in zip_longest(uncompleted, completed, fillvalue=""):
            if u_task or c_task:
                result_table.append([u_task, c_task])
    ```

    Позволила очень быстро привести списки к формату столбцов. Поддерживает fillvalue, для заполнения тех, что не влезли. Невероятно удобно!

Я сделал по образу и подобию как с mkdocs.yml и парсинге/создании новых разделов:
